# Репетитор — карманный ИИ-наставник (пробная версия 0.1)

Чат-репетитор по любой теме на базе Claude. Режимы: Объяснить, Урок по шагам, Квиз, Практика, «Объясни мне» (метод Фейнмана). Настраиваемый уровень (новичок / средний / продвинутый).

## Как получить APK (≈5 минут, без установки Android Studio)

1. Создайте на github.com новый репозиторий (можно приватный).
2. Загрузите в него всё содержимое этой папки (Add file → Upload files).
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
4. Через 3–5 минут скачайте артефакт **repetitor-debug-apk**, внутри — `app-debug.apk`.
5. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

Альтернатива: откройте папку `android/` в Android Studio и нажмите Build → Build APK(s).

## Первый запуск

Приложение попросит API-ключ Anthropic (console.anthropic.com → API Keys). Ключ хранится только на телефоне. Модель по умолчанию — `claude-sonnet-5-5`, её можно сменить в настройках.

## Быстрый тест без APK

Файл `web/index.html` — это то же приложение. Откройте его в браузере телефона или компьютера, чтобы сразу проверить. Если браузер блокирует запросы к API, используйте APK: там запросы идут через нативный слой.

## Состав

- `web/index.html` — весь интерфейс и логика (единый источник).
- `android/` — оболочка WebView на Kotlin без внешних зависимостей; `assets/index.html` копируется из `web/`.
- `.github/workflows/build-apk.yml` — автосборка debug-APK.

## Ограничения пробной версии

Ответы приходят целиком (без потоковой печати), история одна, голосового ввода и иконки приложения пока нет. Debug-APK подписан отладочным ключом — для магазина приложений нужна release-сборка.
